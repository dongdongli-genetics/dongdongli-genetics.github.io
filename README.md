# Dongdong Li Personal Website

This is a static academic website designed for GitHub Pages. The visual direction is intentionally
minimal and academic, inspired by the al-folio Jekyll theme.

## Files

- `index.html` - about/home page
- `research.html` - research page
- `my-publications.html` - selected publications page
- `public-resource.html` - public research resources page
- `r-quantitative-genetics.html` - R and quantitative genetics notes page
- `classical-publication.html` - classical publication reading list
- `cv.html` - curriculum vitae page
- `blog.html` - blog and updates page
- `assets/` - local research images copied from the original Google Site
- `styles.css` - visual design and responsive layout
- `script.js` - mobile navigation and footer year
- `GITHUB_PROFILE_README.md` - optional profile README draft for your GitHub user profile

## Pages

The Home page also includes profile links, education and appointments, recent news, and the visitor counter.

## Visitor Map

The website includes a styled world map and a live country-level visitor counter image using GitHub
Visitor Counter. After the GitHub Pages URL is final, update the `username` and `project` values in
the visitor counter image URL so the count belongs only to this site. For a fuller interactive map,
create a free widget from a service such as MapMyVisitors, PulseMaps, or ClustrMaps, then replace the
visitor counter block in `index.html` with the embed code they provide.

## Publish With GitHub Pages

1. Create a GitHub repository named `dongdongli-genetics.github.io`.
2. Upload all `.html` files, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In GitHub, open `Settings > Pages`.
4. Choose `Deploy from a branch`, then select `main` and `/root`.
5. Your site will appear at `https://dongdongli-genetics.github.io/`.

For a project repository instead of a main profile site, use the same files and enable Pages for that repository.
